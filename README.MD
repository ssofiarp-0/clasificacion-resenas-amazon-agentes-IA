# 📦 Clasificación Automática de Reseñas de Amazon con Pydantic AI

Este proyecto es una solución modular construida en Python que utiliza agentes autónomos impulsados por **Pydantic AI** e integración con la API de OpenAI (usando el modelo `gpt-4o-mini`). El objetivo es procesar, clasificar y organizar automáticamente archivos de texto con reseñas de productos de Amazon alojados en una bandeja de entrada local.
